# Source artwork

The full-size originals of the images the theme ships. Nothing here is imported, so
none of it reaches the storefront.

| Original | Shipped as (`app/assets/images/`) | Size | Shown at |
| --- | --- | --- | --- |
| `teal_logo_trim.png` 640×384 | `teal_logo_trim.webp` | 261×157 | header logo, up to 87×52 |
| `white_logo_trim.png` 640×384 | `white_logo_trim.webp` | 231×139 | footer logo, 77×46 |
| `white_logo.png` 600×600 | `white_logo.webp` | 480×480 | hero bow, 240×240 |
| `teal_pattern_with_bg.jpg` 626×820 | `teal_pattern_with_bg.webp` | 626×820 | background pattern |

Shipped sizes are three times the largest display size for the logos and twice for the
bow, so they stay sharp on phone screens. To change an image, replace the original here
and export it again at the size in the table.
